# AI Panel Studio 产品需求文档

原始作业摘录见[背景与业务需求](../要求/背景与业务需求.md)。

## 用户路径

1. 发起者在首页输入话题并选择专家人数，默认 4 位。系统生成一位主持人及所选数量的专家，展示姓名、职业或头衔、立场和专属颜色。
2. 发起者确认阵容后，主持人开场，讨论进入演播厅。生成失败时，界面应给出明确反馈。
3. 访客可从首页进入进行中的场次，查看已有实录并接收后续更新。

## 功能与验收条件

| 功能 | 验收条件 |
| --- | --- |
| 首页与阵容 | 首页可发起讨论，只列出进行中的场次。默认阵容包含 1 位主持人和 4 位专家。确认后才开场。 |
| 讨论与实录 | 主持人负责开场、追问、串联和总结。专家根据当前实录决定举手、抢答、补充或反驳，允许同一专家连续发言。正式发言每次 1–2 句，实录展示发言者、职业或头衔及对应颜色。 |
| 专家状态 | 每位专家有独立区域，展示待机、准备发言及发言中状态，可显示公开关注点或摘要。隐藏推理和内部意向保持私密。 |
| 共识、分歧与总结 | 讨论进行时持续更新共识与分歧，结束后由主持人提供自然语言总结。 |
| 场次隔离 | 同时运行两场不同话题，双方的状态、事件流、实录、共识与分歧各自独立。 |
| 本地运行与界面 | 前后端分离并可本地运行，密钥从后端环境变量读取。中文界面适配超宽屏、普通桌面与窄屏，各区域独立滚动。 |
